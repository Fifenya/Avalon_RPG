# 🛡️ AVALON 4.0 — СПРАВОЧНИК АДМИНИСТРАТОРА

## Доступ
Админы задаются в .env: ADMINS=123,456. Все команды ниже проверяют ID.

## Команды управления
| Команда | Действие |
|---|---|
| /admin, /admin_help, /ahelp | Справка админа |
| /admin_stats | Статистика игры |
| /online | Игроки онлайн |
| /server_status | Состояние сервера |
| /tech | Режим технических работ |
| /broadcast <текст> | Рассылка всем игрокам |
| /restart | Перезапуск бота |
| /emergency_stop | Экстренная остановка |
| /leave, /leave_chat | Покинуть чат |

## Игроки и данные
| Команда | Действие |
|---|---|
| /check_player <id> | Карточка игрока |
| /fix_tg | Починить tg-юзернеймы |
| /cleanup_phantom | Удалить игроков-фантомов |
| /chatid | Показать ID текущего чата |

## Ошибки и бэкапы
| Команда | Действие |
|---|---|
| /check_errors | Проверка ошибок базы |
| /fix_all | Автоисправление ошибок |
| /list_backups | Список бэкапов |
| /restore_backup <имя> | Откат на бэкап |
| /cleanup_backups | Удалить старые бэкапы |

ВАЖНО: не правь avalon_data.json руками при запущенном боте — только через бэкапы!

## Нейросеть (ИИ врагов)
| Команда | Действие |
|---|---|
| /ai_status | Состояние ИИ |
| /ai_analytics | Аналитика обучения |
| /ai_memory | Память врагов |
| /ai_graph @ник | График обучения (текстовый без matplotlib) |
| /ai_reset, /reset_ai | Сброс ИИ |

## Прокси
/convert_proxy, /refresh_proxies — управление прокси (PROXY_ENABLED в config.py).

## Прочее
/casino — открыть казино-меню.

## Регламент
1. Перед любыми изменениями базы — /list_backups и свежий бэкап.
2. Рассылки — только по важному поводу.
3. Логи ошибок смотри в терминале и папках battle_logs/, reports/.
4. Отчёты зависимостей: reports/dep_report_*.log — читай при сбоях запуска.
